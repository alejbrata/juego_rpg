## Decisión y trazabilidad de adquisición

No hay un Kael gratuito simultáneamente aprobado en calidad, archivos accesibles ya verificados, animación y licencia clara para este flujo. Los candidatos gratuitos existen; no se afirma haber agotado todo el mercado. Los mejores aproximados encontrados requieren compra o aclaración contractual. Se aplica la salida de **informe, sin piloto externo**, prevista por la tarea.

J1/J2/J3 son una **propuesta artística condicionada**, no una autorización de uso ni de compra. Antes de adquirir: confirmar contrato completo aplicable a la tienda, permiso para el flujo asistido por Codex, condiciones de colaboradores y almacenamiento privado; el usuario decide presupuesto/diseño. Ninguna licencia propietaria permite presumir que subir el FBX o GLB a Git público es distribución de un juego terminado. Mantener fuentes privadas o usar un mecanismo local de adquisición autorizado si se elige esa vía.

Al incorporar un recurso en una futura entrega: conservar licencia exacta original, URL, autor, fecha/edición, comprobante sin datos sensibles, hashes del archivo adquirido y derivados, cambios, créditos y lista de archivos realmente distribuidos. No existe aún un manifiesto de adquisición externo porque **no se ha adquirido ninguno**.
